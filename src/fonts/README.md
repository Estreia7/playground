# Fonts

Self-hosted so a build never depends on reaching Google Fonts. Latin subset,
taken from the Fontsource packages (`@fontsource-variable/*`, `@fontsource/*`).
Every family here is licensed under the SIL Open Font License 1.1.

| File | Family | Used by |
| --- | --- | --- |
| geist.woff2, geist-mono.woff2 | Geist, Geist Mono (variable) | root, crypto, fx |
| schibsted-grotesk.woff2 | Schibsted Grotesk (variable) | reorgsi, fx |
| sora.woff2, instrument-sans.woff2 | Sora, Instrument Sans (variable) | host-analyzer |
| ibm-plex-mono-{400,500,600}.woff2 | IBM Plex Mono | host-analyzer, lfp |
| chakra-petch-{500,600,700}.woff2 | Chakra Petch | crypto |
| fraunces.woff2 | Fraunces (variable, all axes) | lfp |
| public-sans.woff2 | Public Sans (variable) | lfp |
